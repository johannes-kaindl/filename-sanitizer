## Getting help

Something missing or wrong? [Open an issue](https://github.com/johannes-kaindl/filename-sanitizer/issues) with the Obsidian version, your platform and, if a file was not renamed, the reason shown on its card in the review list. The plugin's settings also carry a **Report an issue** button.
